# Code of conduct

## Our standard

This is a small, technical project. Participants are expected to:

- be respectful and specific when disagreeing about code, design, or evidence;
- assume good faith, but ask for reproductions and sources rather than guessing;
- keep discussion on the technical problem, not the person;
- respect privacy: do not publish other people's credentials, logs, account data, or private research;
- follow the security-reporting process for vulnerabilities.

Unacceptable behavior includes harassment, discriminatory language, personal attacks, deliberate
misrepresentation of results, publishing private information, and sustained disruption of discussions.

## Scope

This standard applies in repository issues, pull requests, discussions, and other project spaces, and
when representing the project elsewhere.

## Reporting

Report a concern privately to the maintainer, [@lee88688](https://github.com/lee88688), through GitHub.
For security vulnerabilities, use the private advisory link in [SECURITY.md](SECURITY.md) instead.

Reports will be reviewed in good faith and kept confidential as far as practical. Maintainers may
remove content, close discussions, or block participants when behavior violates this standard.
