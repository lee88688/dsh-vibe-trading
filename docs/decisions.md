# 设计决策（decisions）

> 这里记录**已经定下、不再重复讨论**的设计取舍，以及被推翻的旧决策。任务/待办不放在这里（用 GitHub Issues）。
> 改决策的流程：先改本文件，再改 [`architecture.md`](architecture.md)，最后改代码。
> 新决策追加编号（D23 起）；被取代的旧决策保留原文并加删除线，注明取代者。
